| MAP close | Live | Confirmed 1H/4H → `map-latest.json` + optional webhook. A dump that fails (`EPERM` on Windows when another handle holds the file) releases its bars and retries on the next closer tick, and the rename itself retries 4× — one lock no longer costs an hour of stale MAP. The first tick after boot publishes the file without firing the webhook or the accept path, so a restart does not leave `/map-latest` as old as the last close before it. 4H auto-accepts `/zones` via MAP_ACCEPT pick then agent policy (`MAP_ACCEPT=0` off = no copy; `AGENT_MAP=0` = policy no-op, old copy still runs). Family paper score ranks before the per-symbol cap when history exists. No auto-arm. `MAP_CLOSE=0` off. |

Sampled family score/`avgRealizedRr` floor at accept (`family_floor`; `PAPER_FAMILY_FLOOR_MIN_TRADES` default 2). Optional MAP skip via `PAPER_MAP_SKIP` (unset = none). `AGENT_BIAS_CHOP` default deny; `0` off; `proximal` = 4H chop only if last is in proximal→entry. `AGENT_TA_OSC=accept` is an opt-in MAP deny when RSI/div opposes the zone (`ta_osc`; missing osc is not a veto). P7 ARM gates are setup-aware (`src/agent/strategy.ts`). `PAPER_ZONE_SCORE_RR=1` ranks MAP/ARM by sampled `avgRealizedRr` then score (default off). `AGENT_QUANT=0` off. Paper-only. |

| Paper replay-map | Live | `bun run paper replay-map [SYMBOL] --days 180` (or `--from --to`). Omit symbol = watchlist (10). `--one-book` one equity. `--train-days 90` freezes family floor for the holdout. Walk confirmed 4H detect → MAP policy → 15m ARM/OCO. No future bars. Quant tape **as-of**. `quantCoverage` counts ok vs missing per field (flow/cascade empty window is missing, not 0). `skipReasons` counts MAP denials (`family_floor`, `map_skip`, bias, quant, `rr_fail`, `ta_osc`) and unique ARM TA waits (`ta_fib`/`ta_vol`/`ta_shock`/`ta_rev`) separately from ledger `cancelCodes`. `--one-book` applies `AGENT_TA_OSC` the same as single-symbol. Metrics cover the window (not a trailing 7d). Slippage 0. Per-symbol `*-replay-map-SYMBOL.sqlite` unless `--one-book`. Empty tape → `skipped`. Retention `klinesDays` 180. `PAPER_MAP_SKIP` optional (unset = none). |
| Decision corpus | Live | Every MAP evaluation is labelled with its as-of features: `MINH_DECISION_FILE=<path>` appends one JSONL record per card (`v:1`, card geometry, bias 4H/1H/htf, tape readings, family score/trades/RR, `allow`, `reason`). The live accept path and `replay-map` both write it, so a 180d walk yields thousands of labels instead of a verdict count. `bun run agent corpus [--days N] [--json]` ingests into `data/decisions.sqlite` (keyed `asof + zoneId`, idempotent) and reports rows/cards/span/accept rate, counts by reason · setup · side · freshness · htf bias · symbol, and tape coverage as `N known / M missing` — missing is never read as no signal. A row is an evaluation, so `allow evals=N cards=M` prints both; `M` is what `paper review` calls `accepted[]`. `--days N` counts back from the newest decision, not from the wall clock, because walk rows carry past close times. One row per card per close (`asof + zoneId`): a walk that re-evaluates a standing card keeps the first verdict and reports the count, and two flag arms in one db take the same path — each arm gets its own `--db`. `bun run paper replay ...` unaffected; `MINH_DECISION_LOG=1` still prints to stdout for journald hosts. |
| Slot allocation (strategy) | Live | `src/strategy/allocate.ts` owns one decision: which card of a symbol takes the last MAP slot when `LEDGER_CAP_PER_SYMBOL` (2) is the binding gate. `PAPER_MAP_ALLOCATE=feed` (default) hands it out in `/zones` arrival order — the desk's shipped behaviour; `rank` uses ARM's own comparator (family score → realized RR under `PAPER_ZONE_SCORE_RR` → card RR → zoneId). Cards that fail any other gate never compete, so a chop denial cannot hold a slot from a card that would pass, and a slot loser still reads `ledger_cap` at the same point in the chain, keeping `skipReasons` and the corpus comparable. **An incumbent keeps its own seat**: a card already on the ledger is one of the standing cards, so it is not re-priced against the cap it already occupies. Without that rule a symbol at 2/2 labelled both of its own standing cards `ledger_cap` — invisible on the desk (`acceptZone` hits `duplicate_zone` first, so the outcome is a no-op) but published raw by the live-shadow, so `term` showed a deny on cards the desk was holding and the decision corpus recorded the same mislabel. The paper desk, the live-shadow plan and both `replay-map` paths call it, which is the fix: they previously used three different orders (desk arrival, shadow RR, walk family-score-when-present), so the terminal's `shadow=deny ledger_cap` could disagree with the desk and the walk did not measure the host. `test/strategy/parity.test.ts` locks desk == shadow in both modes. Pure function, no DB, no engine, does not arm or place. |
| Paper review | Live | `bun run paper review FILE.json` — compact QC from a replay-map JSON (one-book / single / watchlist `rows[]`). Records its own method (`days`, `oneBook`, `trainDays`, `slippage`) and reports which allocator the walk ran (`allocate`: `feed` / `rank` / `null` — `null` means a pre-allocator JSON, or `AGENT_MAP=0`, whose legacy copy path ranks by score on its own and never reaches `planMapAccept`). Flags: `hype_accepted`, `flow_missing`, `cascade_missing`, `tape_skipped`, `quant_missing`, `coverage_absent`. `bun run paper ab BASE.json VARIANT.json` is variant minus base (one flag at a time; `deploy/replay-map-ab.sh`) and prints `methodMismatch` + a `NOT COMPARABLE` stderr line when the two walks differ on the **instrument** — `days` / `oneBook` / `trainDays` / `slippage`: an in-sample floor and a frozen-floor holdout are two experiments, not an A/B. A knob under test (`allocate`, `chop0`, `arm5`, any TA flag) is deliberately **not** in that list — it is the difference the arm exists to measure, and the first version of this line put `allocate` there, which made `replay-map-ab.sh allocate` report its own comparison as NOT COMPARABLE. Does not walk bars. Lab: [`deploy/replay-map-lab.sh`](../deploy/replay-map-lab.sh) (defaults `PAPER_LAB_TRAIN_DAYS=90`, clears every A/B knob first, names artifacts `-t<train>`). A/B: [`deploy/replay-map-ab.sh`](../deploy/replay-map-ab.sh) (one flag: `baseline` / `chop0` / `floor1` / `arm2` / `arm5` / `arm0` / `allocate` / `skiphype` / `fib` / `osc` / `vol` / `shock` / `rev` / `sd` / `breakout` / `reversal` / `fresh` / `impulse` / `be` / `scorerr`; `MINH_ROOT` now defaults to the checkout the script sits in). |
| Paper operator surface | Live | `paper status` / `paper observe` / `paper event` / `paper arm` / `paper day` / `paper week` — desk, observer snapshot, OCO event, limit+alert (blocked when `PAPER_OBSERVE=1`), UTC session, 7-day funnel. Every one of them prints raw JSON; the human view is the terminal below. |
| Trading Terminal (T3) | Live | `bun run term` — one looping text screen over feed `GET /observe` (paper desk embedded; falls back to `:43181/paper/observe` on a split host), feed `GET /zones?interval=240` and `$LIVE_SHADOW_URL`: feed WS/lag/age, gates + reasons, last MAP dump age, tape `ok` vs `missing` per field, equity and Δ%, standing counts, each open with unrealised PnL as a multiple of **original** risk, resting OCO, armed alerts, mutation lock, shadow, recent events, and a **`MAPCARDS`** block joining all three sources — every detected card with the stage the desk reached (`paper=open|armed|accepted`) and the policy reason the shadow gave (`shadow=deny family_floor`), plus a `plan=` age so stale verdicts read as stale. That is the live answer to "why is nothing armed", which `skipReasons` in a replay JSON used to be the only place to read. `--once` for scripts, `--interval <s>`, `--feed` / `--paper` to point elsewhere. **Viewer only** (ROADMAP lock): it holds no engine, no store, and issues `GET` and nothing else. A source that did not answer renders `down`, a missing tape field renders `—` / `N miss`, a card with no verdict renders `none` (not `deny`), never a zero that looks like coverage. |
| Observe lock | Live | Host `PAPER_OBSERVE=1`: `GET /observe` (feed + gates + last MAP + tape ok/missing + fail-soft live-shadow + paper desk) and `GET /paper/observe`, whose `mutations` reads `exits-only`. Lock splits by direction, not method: entries (`open`, `limit`, `arm`, zone accept/reject, `alert-set`) **403**/reject, exits (`close`, order + alert `cancel`, `mark`) are served — getting flat is never locked. MAP/ARM/EVENT still run in-process. Empty CVD/liq window is missing, not 0. |
| Live shadow | Live | `bun run live` / `src/live/` — separate process, own sqlite, bind `:43182`. Mirrors MAP/ARM policy without `acceptZone` / `paperArm` / orders. Family always cold. `GET /live/health`, `GET /live/shadow` (accepted + `map_plan` verdicts per card, which is what the terminal joins), `POST /live/map-close`. Polls feed `/map-latest` every `LIVE_MAP_POLL_MS` (default 30s, not every ARM tick) and takes a 4H bar once — a bar is consumed only by a cycle that actually evaluated its cards, so a gate-denied boot cycle retries on the next allowed poll instead of muting the bar. A **standing card is not re-accepted**: it keeps the seat it holds and its original `accepted_ts`/`expires_ts`, so `plan.accepted` lists only newly taken slots and an 8-day card still ages out (the desk gets the same guarantee from `duplicate_zone`, thrown before it writes). `LIVE_SHADOW=0` off. See [ROADMAP.md](ROADMAP.md) |
| Paper entry kill-switch | Live | New `paper open` / `paper limit` / `POST /paper/positions` / `POST /paper/orders` / `paper arm` reject when `GET /health` WS is down (`feed_unhealthy`) or `klineLag.ok=false` (`kline_lag`). `/brief-pack` `gates: { tradingAllowed, reasons }`. Does not auto-close opens. No extra mid-range alerts. |
| Paper metrics | Live | SQLite `paper_events` + closed positions. `GET /paper/metrics?days=N` / `bun run paper metrics --days N`. Win rate, avg RR, no_fill%, funnel (detected→accepted→armed→touched→filled/cancelled→exited). `cancelCodes` splits noFill into `never_touched` vs `ops_cancel`; submit-time `kline_lag` / `feed_unhealthy` / `rr_below_min` increment `gates_block` / `rr_fail`. Bound pending tags `deep_mitigate` / `htf_break` / `expired` when the ledger card dies. `byFamily` / `score` rank MAP accept from 7-day paper stats (`PAPER_ZONE_SCORE=0` off). Optional `zoneId` on open/limit/arm. `/zones` does not auto-arm. |
